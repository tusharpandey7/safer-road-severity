# SAFER Road Severity Lab

Compact Streamlit project for exploring the supplied synthetic crash-severity datasets, predicting Slight/Serious/Fatal severity, reviewing model metrics, and viewing a local SHAP explanation.

## Run from PowerShell

Open PowerShell in this extracted folder:

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

If `streamlit` is not recognized, use:

```powershell
python -m streamlit run app.py
```

The ZIP includes the fitted model and both datasets, so you do not need to run training first. Python 3.11 or newer is recommended. The requirements are pinned to match the included model artifact.

## Included files

- `app.py`, `app_pages/` — Streamlit app pages.
- `src/` — prediction, SHAP explanation, dataset loading, and model training code.
- `data/synthetic_dataset_A_10000.csv` — Dataset A.
- `data/synthetic_dataset_B_5000.csv` — independent synthetic sample B.
- `data/metrics_*.csv`, `data/class_report_*.csv`, `data/confusion_*.csv` — evaluation tables used in the app.
- `trained_model/safer_raae.joblib` — fitted adaptive ensemble.
- `outputs/interactive_model_metrics.json` — metrics from the included model refit.
- `requirements.txt` — pinned Python dependencies.
- `DEPLOYMENT.md` — local and internet hosting notes.

## Important scope

Both datasets and their severity targets are synthetic. Dataset B is generated by the same simulator, so it is not real-world external validation. The model classifies severity conditional on a collision scenario; it does not predict whether a crash will occur. Scores are not calibrated real-world probabilities.
