# SAFER Road Severity Lab

Compact Streamlit project for exploring three synthetic crash-severity datasets, predicting Slight/Serious/Fatal severity, reviewing model comparisons and calibration, and viewing a local SHAP explanation.

## Run from PowerShell

Open PowerShell in this extracted folder:

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

If `streamlit` is not recognized, use:

```powershell
python -m streamlit run app.py
```

The package includes the fitted model and all three datasets, so you do not need to run training first. Use Python 3.13 for the pinned dependencies and fitted model artifact.

## Included files

- `app.py`, `app_pages/` — Streamlit app pages.
- `src/` — prediction, SHAP explanation, dataset loading, and model training code.
- `data/synthetic_dataset_A_10000.csv` — Dataset A, used for model fitting and development/test partitions.
- `data/synthetic_dataset_B_5000.csv` — separately generated same-simulator evaluation sample.
- `data/synthetic_dataset_C_prior_shift_2000.csv` — low-Fatal-prior stress sample selected from B without replacement; it overlaps B by design.
- `outputs/ensemble_comparison.csv` — base learners and uniform/adaptive ensemble results on A, B, and C.
- `outputs/paired_bootstrap_comparisons.csv` — 1,000 paired bootstrap comparisons against uniform soft voting.
- `outputs/calibration_metrics.csv`, `outputs/reliability_diagram_points.csv` — Brier score, log loss, expected calibration error, and reliability-curve values.
- `data/class_report_*.csv`, `data/confusion_*.csv` — class reports and confusion matrices.
- `trained_model/safer_raae.joblib` — fitted adaptive ensemble.
- `outputs/interactive_model_metrics.json` — metrics from the included model refit.
- `requirements.txt` — pinned Python dependencies.
- `DEPLOYMENT.md` — local and internet hosting notes.

## Important scope

All three datasets and their severity targets are synthetic. Dataset B is generated by the same simulator, and C is a prior-shift subset of B; neither provides independent real-world validation. Calibration is selected on synthetic validation data and can degrade log loss under prior shift. The model classifies severity conditional on a collision scenario; it does not predict whether a crash will occur. Scores are not calibrated real-world probabilities. The adaptive ensemble's paired confidence intervals do not establish a consistent improvement over uniform voting. See `EXPERIMENT_UPDATE.md` for exact results and limitations.
