# SAFER experiment update: Dataset C, calibration, and ensemble comparison

## Design

Dataset A (10,000 synthetic records) is split once with stratification into 60% model fitting, 10% calibration, 10% validation, and 20% final test. The three base learners are class-weighted Logistic Regression, Random Forest, and LightGBM. Their probabilities are combined using uniform soft voting, entropy-adaptive weighting, and entropy plus model-disagreement weighting. The disagreement penalty is selected from beta values 0, 0.5, 1, and 2 using validation macro-F1. Calibration candidates are raw probabilities, one-vs-rest Platt scaling, and one-vs-rest isotonic scaling. The calibration method is chosen on validation log loss. A separate Fatal alert cutoff is selected on validation data after calibration.

Dataset B (5,000 separately generated examples) is reserved for same-simulator evaluation. Dataset C has 2,000 rows sampled without replacement from B, with 1,500 Slight, 470 Serious, and 30 Fatal rows. It is a synthetic low-Fatal-prior stress test. Because it is a subset of B, B and C are not independent test samples. No feature or label is altered to create C.

## Results

| Evaluation | Selected SAFER accuracy | Balanced accuracy | Macro-F1 | Fatal precision | Fatal recall |
|---|---:|---:|---:|---:|---:|
| Dataset A untouched test (2,000) | 75.00% | 76.57% | 74.92% | 70.52% | 91.71% |
| Dataset B same-simulator (5,000) | 75.18% | 76.49% | 75.00% | 70.59% | 90.34% |
| Dataset C prior-shift (2,000; 30 Fatal) | 76.85% | 77.09% | 57.31% | 17.20% | 90.00% |

The separate Fatal threshold prioritizes recall and produces many false Fatal alerts in Dataset C: 90% recall but 17.2% precision. The ordinary argmax ensemble has better macro-F1 on C (63.95%) and much higher Fatal precision (27.91%), but lower Fatal recall (80%). Accuracy alone hides this trade-off.

For the ordinary ensemble comparison on Dataset A, uniform soft voting obtains 77.45% accuracy and 77.82% macro-F1. The validation-selected beta=2 configuration obtains 77.15% and 77.54%, respectively. Its paired 1,000-resample 95% intervals for differences versus uniform voting are [-0.80, +0.15] percentage points for accuracy, [-0.69, +0.23] points for balanced accuracy, and [-0.76, +0.18] points for macro-F1. All span zero, so the experiment does not establish that the disagreement-weighted ensemble improves on uniform voting. The selected beta is a reproducible validation choice, not proof of a superior method.

On Dataset A test, isotonic scaling has Brier score 0.3119 and macro one-vs-rest ECE 0.0250, compared with raw 0.3179 and 0.0430. However, isotonic log loss (0.5311) is slightly worse than raw (0.5230), and its Brier score and log loss also worsen on Dataset C relative to raw probabilities. Calibration gains therefore depend on the metric and the data distribution; they do not transfer automatically under prior shift.

## Interpretation and limits

These numbers measure recovery of labels generated by SAFER's own declared synthetic simulator. The experiment is useful for checking implementation, class imbalance behavior, selection discipline, threshold trade-offs, and probability calibration within that simulator. It cannot show that the model predicts real crash severity accurately. Dataset B uses the same simulator, and Dataset C reuses B rows. There is no independent real crash test set in this package. Do not describe these metrics as real-world accuracy or the probabilities as real-world risk.

The reported Fatal threshold is a screening-style operating point, not a default severity class rule. Always display the three calibrated class scores and the threshold-based alert separately. In a real application, the model would require a representative, legally usable crash dataset, leakage review, temporal/geographic external validation, recalibration, and review of false-negative and false-positive costs.

## Reproducibility

Run `python src/generate_dataset_c.py` to recreate Dataset C, then `python src/train_model.py` from the project root to regenerate the model, comparison tables, calibration tables, reliability points, and class reports. Seeds and output locations are declared in the scripts. Dataset C metadata is in `data/dataset_C_metadata.json`.
